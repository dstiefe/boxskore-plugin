# Boxskore for Claude

Ask Claude about your program's own baseball data in Boxskore. The plugin connects Claude to
Boxskore; every answer comes from your account after you sign in, and you only ever see what
your Boxskore account can already see.

You need a Boxskore coach account. Installing the plugin does not grant access to any data.

## Install in Claude Code

```
claude plugin marketplace add dstiefe/boxskore-plugin
claude plugin install boxskore@boxskore-plugins
```

Then run `/mcp` and sign in with your Boxskore account.

## Install in the Claude app

Customize > Plugins > Add marketplace, enter `dstiefe/boxskore-plugin`, then install
**Boxskore** and connect it from the plugin's Connectors tab with your Boxskore login.
